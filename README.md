# Emendas Polars

Интерактивный дашборд для анализа государственных расходов Бразилии. Проект собирает открытые данные о парламентских поправках (кто, куда и сколько выделил денег), очищает их и показывает в виде удобных графиков прямо в браузере.

Подойдёт журналистам, исследователям и всем, кто хочет проверить, как депутаты тратят бюджет, не копаясь в огромных и грязных CSV-таблицах.

## Возможности

- **Автоматический сбор данных:** Пайплайн сам скачивает свежие архивы с портала прозрачности.
- **Умная очистка:** Данные приводятся в порядок (форматирование дат, валют, текста) с помощью сверхбыстрой библиотеки Polars.
- **Работа без сервера:** Дашборд использует DuckDB-Wasm, поэтому все SQL-запросы выполняются прямо в вашем браузере. Никакие данные никуда не отправляются.
- **Автообновление:** Благодаря GitHub Actions данные и графики обновляются каждый день автоматически.

## Требования

- Python 3.9 или новее
- ОС: Linux, macOS, Windows
- Установленный `pip` (менеджер пакетов Python)
- Современный браузер (Chrome, Edge, Safari). Примечание: в Firefox есть известный баг с загрузкой данных.

## Установка и запуск

Вы можете запустить обработку данных локально, чтобы проверить работу пайплайна.

1. Клонируйте репозиторий:
git clone https://github.com/matheusesilva/emendas-polars.git
cd emendas-polars

text

2. Установите необходимые зависимости:
pip install polars duckdb pyyaml requests

text

3. Запустите ETL-пайплайн (скачивание, очистка и подготовка данных):
python main.py

text

После выполнения команды в папке `data/` появятся готовые файлы для дашборда.

## Пример использования

Чтобы увидеть дашборд, вам не нужно запускать код. Просто откройте [живую демонстрацию](https://matheusesilva.github.io/emendas-polars/).
